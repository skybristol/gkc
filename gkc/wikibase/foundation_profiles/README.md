# Foundation Profiles

These files define the baseline Data Distillery ontology in a machine-readable form.

## Files

- `foundation_entities.yaml`
- `foundation_properties.yaml`
- `foundation_metadata.yaml`

## Notes

- During early setup, IDs (`Q...`, `P...`) are optional.
- Audit workflows resolve existing identifiers by exact label matching.
- After initialization, you can populate explicit identifiers in these files.
